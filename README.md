# ごんぎつね 学習アプリ

小学4年 国語（光村図書）の物語文「ごんぎつね」（新美南吉）を学習するための React アプリです。ひとりぼっちの小ぎつね「ごん」といっしょに、読む／問題／漢字／場面マップ／対比表（いたずら⇄つぐない）の5モードで、登場人物の心情・場面の移り変わり・物語の主題（ごんと兵十の思いのすれちがい）を段階的に読み深められます。テスト頻出の読み取り・抜き出し問題を多数収録しています。

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
