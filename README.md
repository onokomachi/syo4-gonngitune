# 一つの花 学習アプリ

小学4年 国語（光村図書）の物語文「一つの花」（今西祐行）を学習するための React アプリです。コスモスの花のせい「コスモちゃん」といっしょに、読む／問題／漢字／場面マップ／対比表（戦争中⇄十年後）の5モードで、登場人物の心情・場面の移り変わり・物語の主題（題名「一つの花」にこめられた願い）を段階的に読み深められます。テスト頻出の読み取り・抜き出し問題を多数収録しています。

View your app in AI Studio: https://ai.studio/apps/d40a24f2-53ab-4444-a5c7-55974261c9fb

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
